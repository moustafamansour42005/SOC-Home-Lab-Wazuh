# Threat Hunting

## Purpose

Threat Hunting is used after detection to investigate the timeline, identify related events, and understand the attack behavior.

## Brute Force

The project filters the Wazuh Threat Hunting view using:

```text
rule.id: 100005
```

This exposes the alerts generated by the brute-force correlation rule and allows the analyst to correlate them with the Hydra execution timeframe.

## Nmap

The reconnaissance rule is investigated to identify the volume and timing of the generated alerts.

The project recorded 115 hits during a 2.46-second Nmap scan window.

## Investigation Fields

During triage, useful fields include:

- Source IP
- Source Port
- Destination IP
- Destination Port
- Event ID
- Rule ID
- Alert level
- MITRE ATT&CK mapping
- Timestamp
- Related events
